为什么不是又一个预测工具

目标不是猜对结果，
而是把概率估准。

博彩机构不关心谁会赢，只关心概率定得准不准、风险怎么对冲。这套体系按同一套逻辑搭起来：去水、独立建模、逐场回测。

01 / DE-VIG

先去水，再谈价值

竞彩胜平负与让球盘 margin 稳定在 13.8%–14.0%，返还率约 86%。任何概率比较都必须先剔除这层抽水，否则会把抽水误读成边际。

P(i) = (1/odds_i) / Σ(1/odds_j)
02 / OWN MODEL

模型不能只读盘口

用总进球赔率反解胜平负，本质是复述盘口——偏差恒小于 3pp。本体系改用主客分离的得失球建立独立强度模型，再与市场按 k=0.35 融合。

λ = (1−k)·λ市场 + k·λ独立
03 / BACKTEST

回测先于结论

每轮先给上一轮打分，把「实际命中率」与「盘口隐含概率」对照，再用结果改规则。冷端价值、人气缺口都在回测里被证伪并删除。

4 级判定
模型定义

每一个数字，
都有公式。

从赔率到概率不是估计，是一串写死的算式。下面是 analyze.js 里实际执行的数学，报告中的每个百分比都能追回其中某一行。

Layer 1consensus共识 λ

20 家即时欧赔 → Shin 去水 → 2D 拟合总进球 λ 与强弱分配 w。

Layer 2independent独立强度 λ

主客分离得失球，近因半衰期 180 天加权，样本量收缩 K=8。

Layer 3blend融合与封顶

按 k 混合两层 λ，并对位移封顶，跨赛事样本不得推翻市场。

Layer 4intel情报与纪律

联网伤停修正、裁判与球队红牌率、摩擦指数，全部可查源。

01 · De-vig
P(i) = (1/oi) ⁄ Σj 1/oj
pi = [√(z² + 4(1−z)·πi²/S) − z] ⁄ 2(1−z)
上行为比例去水，下行为 Shin 去水：把庄家报价里的内幕交易比例 z 显式建模，校正「热门被高估、冷门被低估」。本项目实测 z = 0.070–0.075，与竞彩 13.9% 抽水一致。
02 · Score grid
P(X = k) = e−λ · λk ⁄ k!
λ 为期望总进球。模型解出 12×12 比分矩阵，胜平负、总进球区间、大小球、双方进球、比分分布全部从这张矩阵读出，不单独建模。
03 · Dixon-Coles
τ(0,0) = 1 − λhλaρ
泊松独立假设低估了 0-0 / 1-1 等低比分。用 ρ = −0.10 修正低比分相关性，同时修正 1-0、0-1、1-1 四个格子，并按 ρ ∈ {0, −0.05, −0.10, −0.15} 做敏感性检验。
04 · 1X2 & handicap
P(主胜) = Σi>j P(i,j)
让球盘用同一张矩阵重算：净胜球 net = i − j + hc。因此「让球主胜」与「胜平负主胜」方向可以相反——强队赢 1 球仍可能输盘，报告必须写清球队与让球数。
05 · Independent strength
att = (gf ⁄ gf̄)p/(p+K)
主客场分开统计，按场次数 p 收缩到联赛均值（K = 8），避免小样本球队被高估：λh = λ̄home · attH · defA。
06 · Blend & cap
λ = λ共识 + clamp[k·(λ独立 − λ共识), ±0.35]
k = 0.35（联赛）/ 0.25（杯赛），庄家样本少时自动收缩。位移封顶保证独立层只能温和修正市场，不会用跨赛事样本整体推翻定价。
07 · Discipline
λred = 0.45·裁判 + 0.35·球队 + 0.20·球员
红牌期望按裁判、球队近一年红牌率与球员风险加权：P(吃红) = 1 − e−λred。深盘热门侧 P(红) ≥ 12% 直接否决，红牌情景单独披露。
08 · Buy gates
EV = p · o − 1 ≥ 3%
edge > ½(pmax − pmin)(σ)
三道闸门同时放行才可推荐：EV ≥ 3%、边际大于 σ 造成的不确定性、EV 在 ρ 四个取值下同号；赔率 < 1.35 与单关关闭一律不产出单场推荐。
09 · Shengfucai coverage
T = Π|Si|
传足复式：每场选择集合 Si 的注数为乘积；命中场次数 K 的分布用独立卷积求出，贪心把预算分配到边际提升最大的双选上，输出全中与 ≥13 场覆盖率。
10 · Uncertainty
σ = σmarket + σteam
λ 的不确定性拆成两项：市场噪声（0.10 + 庄家离散度）与独立层抽样误差（0.30 ⁄ √有效场次）。σ 越大，置信闸门要求的边际越高，越容易「不推荐」。

常见问题

你大概会问的六个问题。

为什么数据要付费，方法论却免费？

方法论是一次性写成的开源代码，已经放在 GitHub 上；而每期数据要重新抓 20 家欧赔、翻十多个联赛的球队赛程、逐个球员核对伤停并附来源，这部分是持续的劳动。所以公式与回测全部公开，当期数据放在会员服务里。

8.8 的会员和 9.9 的报告有什么区别？

会员是「看数据」：30 天内可反复查看当期竞彩与传足的完整概率、λ、σ、伤停来源与复式方案。报告是「拿文件」：一次付费换一次 PDF 下载，文件带你的账号水印。会员不包含报告下载，两者独立计价。

会不会自动续费、偷偷扣款？

不会。会员是固定 30 天有效期，到期自动失效，没有续费接口、没有绑定代扣。想继续用就重新买一次。

为什么很多场次结论是「不参与」？

竞彩单场抽水约 13.9%，大部分场次在去水之后就已是负期望。模型要求同时满足 EV ≥ 3%、边际大于不确定性、ρ 四个取值下同号，才会给出推荐。正常日子的正确答案就是「0–2 场可小注，其余不推荐」，而不是每场都给个方向。

让球盘为什么有时和胜平负方向相反？

让球盘看的是「让球后的结果」，不是谁赢球。主队让 1 球时，主队只赢 1 球算让球平；赢球但没赢够，买让球主胜就是输。所以报告一律写「球队 + 让球数」，比如「客胜（某队 +1）」，避免被读成胜平负。

这些概率能保证赢钱吗？

不能。概率是模型与盘口的推算值，误差由 σ 表达，σ 之内的一切差异都不构成投注理由。本项目的价值在于「把价格还原成概率、并诚实说出哪里没把握」，不是提供稳赢方案。
