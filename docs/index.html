为什么不是又一个预测工具

目标不是猜对结果，
而是把概率估准。

博彩机构不关心谁会赢，只关心概率定得准不准、风险怎么对冲。这套体系按同一套逻辑搭起来：去水、独立建模、逐场回测。

01 / DE-VIG

先去水，再谈价值

竞彩胜平负与让球盘 margin 稳定在 13.8%–14.0%，返还率约 86%。任何概率比较都必须先剔除这层抽水，否则会把抽水误读成边际。

P(i) = (1/odds_i) / Σ(1/odds_j)
02 / OWN MODEL

模型不能只读盘口

用总进球赔率反解胜平负，本质是复述盘口——偏差恒小于 3pp。本体系改用主客分离的得失球建立独立强度模型，再与市场按 k=0.35 融合。

λ = (1−k)·λ市场 + k·λ独立
03 / BACKTEST

回测先于结论

每轮先给上一轮打分，把「实际命中率」与「盘口隐含概率」对照，再用结果改规则。冷端价值、人气缺口都在回测里被证伪并删除。
