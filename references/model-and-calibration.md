# 模型与校准

本文件记录两件事：**定价模型的数学定义**，以及**回测得到的经验校准**。阈值和权重只能从这里改，不允许在报告里临时手调。

---

## 一、v1 的结构性缺陷（为什么必须重写）

v1 的「模型」是这样来的：用竞彩总进球赔率去水得到 P(0 球)，由 λ = −ln P(0) 反解总进球期望，再搜索主场份额 w 使胜平负三项贴合竞彩去水概率。

这个做法有个致命问题：**它输入的只有盘口，输出的还是盘口。** 拟合误差中位 0.8–2.1pp，意味着模型概率与去水概率的偏差恒 <3pp——它不是预测，是盘口的复述。用它去找「定价偏差」等于在量自己的误差。

**v2 必须引入盘口之外的独立信息。**

## 二、v2 定价模型

### 2.1 市场映像（保留）

`fitFromZJQ(zjq, spf)` / `fit2D(spf)`：由盘口反解 λ 与 w。

用途变了：v1 把它当预测，v2 只把它当**市场共识的基准线**，用来衡量独立模型偏离市场多远。

### 2.2 独立强度模型（新增，比率法 + 收缩）

输入是捷报的**主客分离**得失球（不是总数据——主场和客场是两支球队）：

| 符号 | 含义 |
|---|---|
| `hg` | 主队主场场均进球 = 主队主场 gf / p |
| `hga` | 主队主场场均失球 |
| `ag` | 客队客场场均进球 |
| `aga` | 客队客场场均失球 |

联赛基准用两个独立估计互相印证，避免单点噪声：

```
lgHome = (hg + aga) / 2     ← 主队主场进攻力 与 客队客场防守漏勺 的均值
lgAway = (ag  + hga) / 2
```

攻防强度比，再做**样本量收缩** `shrink(x, p) = 1 + (x − 1) · p/(p + K)`，`K = 8`：

```
attH = shrink(hg  / lgHome, 主队主场场次)
defH = shrink(hga / lgAway, 主队主场场次)
attA = shrink(ag  / lgAway, 客队客场场次)
defA = shrink(aga / lgHome, 客队客场场次)

λ_主 = lgHome · attH · defA
λ_客 = lgAway · attA · defH
```

收缩的理由：9 轮样本里「主场场均进 2.0 球」和「真实进攻力 2.0 倍联赛均值」是两件事。`p = 9` 时收缩系数 `9/17 = 0.53`，即把偏离打对折。样本越多收缩越轻，`p → ∞` 时还原为纯比率法。

**近 6 场状态修正**：权重 0.15，且要求双方近 6 场样本 ≥4 场，否则不启用。修正只作用于 λ，不改变 w。

```js
lamH *= 1 + 0.15 * (ratioH - 1)
```

`ratioH` = 近 6 场「进球 0.6 + 失球 0.4」的综合速率 ÷ 赛季同口径速率。权重故意压得很低——状态是最容易被过度解读的变量。

### 2.3 融合

```
λ = (1 − k) · λ_市场 + k · λ_独立,   k = 0.35
w = (1 − 0.5k) · w_市场 + 0.5k · w_独立
```

**k 为什么偏小（0.35）：** 市场 λ 里含首发票、伤停、动机等模型看不到的信息，独断地相信独立模型会丢掉这些。但 k 必须显著大于 0，否则模型回到 v1 的复述状态。0.35 是让独立模型能在 λ 上造成 ±0.3 球量级偏离的最小权重，这个幅度刚好能让概率层面出现 3–8pp 的差异，足以被判定规则捕捉，又不至于压过市场。

**w 为什么给独立模型一半权重：** w 刻画强弱分配，市场对此更准（它见过双方完整阵容），所以独立模型的 w 只影响 0.5k = 0.175 的份额。

### 2.4 从 λ 到全部市场

`grid(λ, w, ρ = −0.10)` 产出 12×12 比分矩阵，然后一次性导出：

| 市场 | 计算方式 |
|---|---|
| 胜平负 | 对角线上/下求和 |
| 让球胜平负 | `net = 主进球 − 客进球 + hc` 三分 |
| 总进球桶 | `min(主+客, 7)` 归并成 8 档 |
| 总进球区间 | 0-1 / 2-3 / 4-6 / 7+ |
| 大小球 2.5 | `主+客 > 2.5` 求和 |
| 双方进球 | `主>0 且 客>0` |
| 正确比分 | 单元格按概率排序取 top-N |
| 半全场 | 上下半场各分 λ/2，枚举 4×4 上半场 × 4×4 下半场按 9 项归并 |

ρ = −0.10 用于压低 0-0、1-0、0-1、1-1 四个低比分格。它修正的是「低比分被独立泊松高估」这一已知事实。

## 三、回测校准（33 场实测）

样本：上一轮 42 场中已完赛的 33 场（8 场凌晨场次日补充确认 + 25 场常规场）。

### 3.1 方向命中率

| 口径 | 命中 | 命中率 |
|---|---|---|
| 去水概率第一方向 | 20 / 32 | **62.5%** |
| 支持率第一方向 | 17 / 32 | **53.1%** |
| 模型第一方向（焦点 7 场） | 5 / 7 | 71.4% |

**结论：跟随市场比跟随人气高 9.4pp。** 人气方向命中率比定价方向低近 10 个百分点，这是本轮最稳的一条。

### 3.2 定价与资金分歧场次

| 编号 | 实际 | 定价倾向 | 资金倾向 |
|---|---|---|---|
| 日018 莱切 vs 热那亚 | 客胜 | 客胜 ✓ | 平局 ✗ |
| 日023 毕尔巴鄂 vs 皇家社会 | 主胜 | 主胜 ✓ | 客胜 ✗ |
| 日024 格雷米奥 vs 米内罗竞技 | 主胜 | 主胜 ✓ | 平局 ✗ |

分歧场次 3 场：**定价方 3/3，资金方 0/3。** 样本极小，但方向与 3.1 一致，因此 v2 把「分歧时采信去水方向」写成硬规则。

### 3.3 冷端 / 热端：v1 的核心逻辑被证伪

v1 报告的核心执行建议是「热端回避 + 冷端价值小注」。用「实际兑现率 vs 盘口隐含概率」检验（这是唯一有统计意义的比较方式）：

| 分层 | 样本 | 实际兑现 | 盘口隐含 | 偏差 |
|---|---|---|---|---|
| 冷端 Δ ≤ −8pp（v1 推荐的价值池） | 30 | 30.0% | 26.3% | **+3.7pp** |
| 中性 −8 < Δ < +10pp | 44 | 22.7% | 30.2% | −7.4pp |
| 热端 Δ ≥ +10pp（v1 建议回避） | 22 | 59.1% | 49.2% | **+9.9pp** |

30 样本的标准误约 8.0pp，22 样本约 10.7pp。**+3.7pp 和 +9.9pp 全部落在噪声内。**

**所以：Δ（支持率 − 去水概率）在本样本中没有可靠的定价含义。** 冷端不构成买入理由，热端也不构成卖出理由。v2 因此取消了「Δ ≤ −8pp 即小注」这条规则。

Δ 唯一保留的用途是**风险提示**：热端 Δ ≥ +15pp 时价格确实不含补偿，标「回避」是价格判断而非胜负判断。

### 3.4 正确比分：单值预测完全失效

焦点 7 场的模型 top-N 覆盖情况：

| 口径 | 命中 |
|---|---|
| top1（唯一比分） | **0 / 7 = 0%** |
| top3 | 3 / 7 = 42.9% |
| top5 | 5 / 7 = 71.4% |

top1 全错。7 场实际比分是 2-2、3-1、2-1、0-1、2-0、2-1、1-2，而模型 top1 有 5 场都是 1-1。

**规则：永不给「最可能比分」单值。** 只给带概率的 top-5 排名分布，并同时给出累计覆盖率。

### 3.5 大小球：唯一表现好的衍生市场

| 口径 | 命中 |
|---|---|
| 大/小 2.5 方向 | 6 / 7 = 85.7% |
| 让球盘（报告给出的那一侧） | 2 / 3 = 66.7% |

33 场实际总进球分布：0 球 1 场、1 球 6、2 球 7、3 球 9、4 球 5、5 球 2、7 球 2、9 球 1。场均 **3.03 球**，大 2.5 占 **57.6%**，双方进球 **57.6%**。

### 3.6 赔率分段（供下一次校准对照）

| 热门赔率 | 实际命中 | 盘口预期 | 偏差 |
|---|---|---|---|
| <1.50 | 8/9 = 88.9% | 66.8% | +22.1pp |
| 1.50–2.00 | 7/12 = 58.3% | 49.8% | +8.5pp |
| 2.00–2.50 | 4/10 = 40.0% | 40.4% | −0.4pp |
| ≥2.50 | 1/1 | 34.9% | — |

超短赔（<1.50）9 场全中 8 场，高出盘口预期 22pp。样本太小不能当结论，但**下一轮要重点复核这一段**：如果连续两轮都大幅高于隐含，说明竞彩在超短赔上有系统性低估。

### 3.9 v3 的三个落地变更

1. **超短赔主推规则**：去水第一方向概率 ≥66% 且模型同向且该侧伤停修正 ≥−0.15 且资金方向无分歧 → 主推单关。方案概率采用回测经验值 91.7%（12 样本，标准误约 8pp），报告中必须加星号注明非模型输出。
2. **injuryAdj 伤停修正**：每队 λ 手动修正（建议区间 −0.4 ~ +0.4），依据为官方伤停 + 媒体交叉确认，报告逐条披露并附否决条件。亚特兰大教训：6 名以上主力缺阵而模型不修正 = 定时炸弹。
3. **购买方案层 `buildRecommendation`**：每场输出 级别（主推/小注/观察/回避）+ 玩法 + 选项 + 赔率 + 概率/隐含 + EV + 仓位 + 否决条件。判定层战绩 4/4 是这套纪律的实证。

### 4.2 第三轮的五条教训

1. **超短赔三轮确认但经验值下调**：本轮 3/4，跨轮累计 14/16 = 87.5%（隐含约 67%）。失利场周三004 利物浦 @1.33 客负费内巴切——败因是伤停评估错误（「利物浦 6 人伤但多为替补」系单一来源判断，实际影响被低估）。**经验值 91.7% → 87.5%（16 样本，标准误约 8pp）**，并新增否决条款：热门侧伤停仅有单一来源且判断为「替补级」时，按修正不足处理（等首发确认再决定）。
2. **injuryAdj 方向正确、幅度存疑**：那不勒斯 −0.35（9 人伤）→ 波尔图 4-1 兑现；但科莫 6 人伤含 4 前锋却 9-1 狂胜，说明**伤停修正对阵容深度足够的球队可能完全失效**。修正幅度必须考虑替补质量，无法量化时保守给值并披露。
3. **新帅效应首个样本**：费内巴切换帅后 3-2 利物浦（主队 5 人伤仍赢）。v4 新增裁定指引：**换帅方（新帅执教 ≤2 场）λ +0.1 ~ +0.15，披露制**，走 injuryAdj 通道。
4. **λ 系统性低估总进球（待验证）**：本轮 λ 均值 3.10 vs 实际场均 4.09；剔除 1-9 异常场后仍低估约 0.3。竞彩总进球赔率反解的 λ 可能系统性保守，累计三轮后再决定是否加修正系数。
5. **方案层战绩口径**：观察级不参与不计战绩；只有主推/小注计入。周三002 观察级总进球大落空不影响方案层战绩。

### 4.3 v4 的落地变更（克制，防过拟合）

1. 超短赔经验值 0.917 → **0.875**（analyze.js `EMP`），pSrc 标注 16 样本。
2. 新增**新帅效应**裁定指引（进 injuryAdj，代码不加硬规则）。
3. 伤停评估**双源确认**要求写入 SKILL.md 数据卫生条目。
4. 方案层战绩口径：主推/小注计入，观察级不计。
5. λ 总进球低估进待验证清单，不改模型。

第五轮（11-08 周日 22 场）细节：让球方向 11/22 = 50.0%，总进球区间 14/22 = 63.6%，总进球单档 7/22 = 31.8%，方案层「可小注」1 场（塞尔塔让主，0-0 落空）。第四轮方案层：主推 3/4、小注 0/3。

### 6.2 第五轮暴露的两个结构性问题

1. **模型与市场分歧 0 场。** 11-08 的脚本只从竞彩赔率反解 λ，未接入捷报主客分离得失球，模型概率与去水概率在 22 场里没有任何一场的 argmax 不同。这与 v1 的「复述盘口」是同一种病，必须在 v5 修掉。
2. **λ 总进球不再系统性低估。** 第五轮 λ 均值 3.12 vs 实际 3.00（偏差 −0.12），第三轮的 −0.99 未复现。因此不加总进球修正系数（避免用一轮噪声改模型）。

### 6.3 超短赔分段：24/32 = 75.0%

第五轮 <1.50 热门 7/9（隐含 66.3%）。五轮合并 24/32 = 75.0%，高出隐含约 8.7pp，**仍在 1 个标准误（约 8.8pp）以内**，因此经验值维持 0.875，不作为独立买入理由，继续累计样本（距 50 场还差 18 场）。

### 6.4 v5 的核心转向：不猜胜负，找错价

五轮累计模型 60.9% vs 去水 60.2%，差异落在噪声内——**模型没有方向性优势**。但竞彩是唯一法定价格，且与海外共识存在真实价差：2026-11-09 场次里，布罗姆利主胜竞彩 4.11、16 家共识均赔 3.48（价差 18%），谢周三主胜竞彩 1.37、共识 1.50。v5 因此把「竞彩 vs 共识的价差」升级为主信号。

### 6.5 v5 的七项落地变更

1. **市场 λ 改用海外共识**：16–17 家即时欧赔均值去水后拟合 λ；竞彩只作为价格与 EV 基准，不再参与定概率。
2. **恢复独立强度层**：捷报主客分离得失球 + `shrink(K=8)` + 近 6 场状态（权重 0.15），并逐场披露独立 λ。

## 七、纪律层：红牌风险因子（v5.1，2026-11-10 设计，未回测）

### 7.1 动机与边界

用户提出把「球员情绪状态 / 吃红牌可能性」纳入预测。**情绪本身不可查询**——没有任何结构化数据源提供可信的球员情绪指标。可行的做法是只保留可观测代理：

| 代理 | 来源 | 可量化？ |
|---|---|---|
| 裁判严格度（场均红/黄牌，样本 200–300 场） | 捷报裁判分析页 | 是 |
| 球队纪律（近 10/5 场场均红黄牌，主客分开） | 捷报裁判分析页 | 是 |
| 累积黄牌停赛（核心球员缺阵） | 官方公告/直播吧 | 是，走 injuryAdj |
| 比赛性质（德比/保级 6 分战） | 联赛形势 | 定性，文字层 |
| 更衣室风波、欠薪、公开冲突 | 新闻 | 定性，文字层，不进 λ |

红牌风险因子只负责「比赛中被罚下」这一件事；停赛是赛前状态，归 injuryAdj。

### 7.2 数学定义

输入（捷报裁判页，可查源）：

```
λ_red(队) = 0.5 × 裁判对该队口径场均红牌 + 0.5 × 该队近10场（本侧）场均红牌
P(队吃红) = 1 − exp(−λ_red)          ← 泊松近似
```

对 λ 的期望修正（效应量级取文献共识，**非本样本回测**）：

```
adj(队) = −0.40·T·P(队吃红) + 0.30·T·P(对方吃红),   T = 0.35
```

- 0.40 / 0.30：10 人作战进攻下降 / 对方提升的量级
- T = 0.35：红牌平均发生在 ~60'，10 人作战的期望时长占比
- 每侧封顶 ±0.12 球；无 discipline 输入时整层不启用

实现于 `analyze.js` 的 `disciplineLayer()`，输出 `pRedH / pRedA / adjH / adjA / hot`（hot = 高摩擦场次标记：任一侧合成场均黄牌 ≥2.3，只披露不改 λ）。

### 7.3 自检样例（非回测）

裁判场均红牌 0.15 + 客队近 10 场 0.30：P(客红) = 20.1%，adjA = −0.021、adjH = +0.011，λ总 2.772 → 2.762。方向正确、量级温和——**这正是设计意图**：红牌是低概率事件，它对单场期望的影响本来就小，把它做成 ±0.12 封顶的温和修正 + 让球/大小盘的披露信息，而不是夸张的胜负翻转器。

### 7.4 待验证清单（第七轮起）

1. **修正方向与幅度**：累计 30+ 场「纪律层启用且 P(吃红) ≥15%」的样本，对比该侧实际红牌发生率与 λ 修正后的大小盘/让球命中率。
2. 效应系数 0.40/0.30/T=0.35 为文献量级，若有 20+ 场「实际吃到红牌」的样本，用红牌发生前后的实际得失球速率重估。
3. 高摩擦场次（hot=true）是否对总进球「大」方向有系统性增益（定位球/点球增多假设）。
4. 裁判页无数据的赛事（低级别杯赛）纪律层自动不启用，不降级报告。
5. 累积黄牌停赛的入模率：统计每轮「停赛导致 injuryAdj ≠ 0」的场次数。

### 8.1 触发事件

### 8.2 六项结构性变更

1. **独立层接入 `analysisJs`**：`http://live.nowscore.com/analysisJs/data{fid}.js` 内含 `h_data`/`a_data`（主队/客队近期全部比赛）。按 `h2h_home`/`h2h_away` 过滤本侧主/客场，得到主队主场、客队客场的得失球；按日期做半衰期 180 天加权；`p` 为加权有效场次，进入 `shrink(K=8)`。样本 <3 场回退全部比赛并标 `venueFallback`。

### 10.2 Shin 去水实现

求 z ∈ [0, 0.5)：

$$\sum_i \frac{\sqrt{z^2 + 4(1-z)\,\pi_i^2/S} - z}{2(1-z)} = 1,\quad \pi_i = 1/odds_i,\ S=\sum\pi_i$$

用二分法 80 次迭代。z=0 时退化为比例去水。2026-11-22 批次实测 z = 0.070–0.075（与 13.9% 抽水相符），差异分布：短赔热门 +2.3~+4.0pp（尤文 1.21、马赛 1.29、AC米兰 1.41、利物浦 1.58），冷门 −1.5~−2.3pp。效果是**短赔场次的「假 EV」被压掉**，与铁律 10（不追热门）方向一致。

### 10.3 σ 拆解

```
σ_market = 0.10 + clamp((mean(consSD) − 0.006) × 8, 0, 0.08)
σ_team   = clamp(0.30 / √(有效场次), 0.04, 0.14)     # 缺独立层时为 0
σ        = σ_market + σ_team + (degraded ? 0.15 : 0)
```

本批中位 σ = 0.18，区间 0.16–0.23（7003 特温特因共识离散度大，σ 0.227）。与 v7 的 0.16–0.19 量级一致，但每一项可解释。

### 10.4 传足层的数学

- **覆盖概率**：给定每场选择集 S_i，命中场次数 K 的分布由独立卷积给出，
  `dist[k+1] += dist[k]·cover_i`，`dist[k] += dist[k]·(1−cover_i)`，`cover_i = Σ_{s∈S_i} p_i(s)`。
  注数 `T = Π|S_i|`，每注 2 元。
- **分配**：从全单选出发，每次把某场从 k 选扩到 k+1，按 `(5·ΔP(全中) + ΔP(≥13))/ΔT` 取最大者，预算外溢 >10% 拒绝（并给 1.25 惩罚系数）。
- **分级**：首二次差 ≥22pp 稳胆 / 10–22pp 博胆 / 4–10pp 双选 / <4pp 全包。
- **任九**：按单场最大概率乘积取前 9 场，输出 `p9 = Π max(p_i)`。

2026-11-22 第 26168 期实测：单选基线 p(全中) = 1.67e-4、p(≥13) = 2.26e-3；27 注 54 元 → p(≥13) = 2.35%；54 注 108 元 → 3.50%；81 注 162 元 → 4.40%。

### 10.5 待验证

1. Shin 去水是否让「短赔热门推荐」的历史回测变好——需要下一轮用同一批比赛对比两种口径的 EV 排序。
2. σ 拆解后闸门通过率变化（本批 0 注，与 v7 一致，未观察到异常）。
3. 传足覆盖概率是**独立近似**（每场只出一个结果，选择集内的选项互斥）；`cover_i` 求和本身是精确的，但 14 场之间假设独立——同期比赛之间的相关性（同联赛同轮）未建模，理论上会让真实覆盖略低于计算值。
4. 传足 3 场非竞彩场次（奥萨苏纳-马拉加、巴黎FC-昂热、洛里昂-雷恩）只有欧赔共识，缺竞彩成交量，模型边际更容易失真。
