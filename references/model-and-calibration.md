# 模型与校准

本文件记录两件事：**定价模型的数学定义**，以及**回测得到的经验校准**。阈值和权重只能从这里改，不允许在报告里临时手调。

---

## 一、v1 的结构性缺陷（为什么必须重写）

v1 的「模型」是这样来的：用竞彩总进球赔率去水得到 P(0 球)，由 λ = −ln P(0) 反解总进球期望，再搜索主场份额 w 使胜平负三项贴合竞彩去水概率。

这个做法有个致命问题：**它输入的只有盘口，输出的还是盘口。** 拟合误差中位 0.8–2.1pp，意味着模型概率与去水概率的偏差恒 <3pp——它不是预测，是盘口的复述。用它去找「定价偏差」等于在量自己的误差。

**v2 必须引入盘口之外的独立信息。**

## 二、v2 定价模型

### 2.1 市场映像（保留）

`fitFromZJQ(zjq, spf)` / `fit2D(spf)`：由盘口反解 λ 与 w。

用途变了：v1 把它当预测，v2 只把它当**市场共识的基准线**，用来衡量独立模型偏离市场多远。

### 2.2 独立强度模型（新增，比率法 + 收缩）

输入是捷报的**主客分离**得失球（不是总数据——主场和客场是两支球队）：

| 符号 | 含义 |
|---|---|
| `hg` | 主队主场场均进球 = 主队主场 gf / p |
| `hga` | 主队主场场均失球 |
| `ag` | 客队客场场均进球 |
| `aga` | 客队客场场均失球 |

联赛基准用两个独立估计互相印证，避免单点噪声：

```
lgHome = (hg + aga) / 2     ← 主队主场进攻力 与 客队客场防守漏勺 的均值
lgAway = (ag  + hga) / 2
```

攻防强度比，再做**样本量收缩** `shrink(x, p) = 1 + (x − 1) · p/(p + K)`，`K = 8`：

```
attH = shrink(hg  / lgHome, 主队主场场次)
defH = shrink(hga / lgAway, 主队主场场次)
attA = shrink(ag  / lgAway, 客队客场场次)
defA = shrink(aga / lgHome, 客队客场场次)

λ_主 = lgHome · attH · defA
λ_客 = lgAway · attA · defH
```

收缩的理由：9 轮样本里「主场场均进 2.0 球」和「真实进攻力 2.0 倍联赛均值」是两件事。`p = 9` 时收缩系数 `9/17 = 0.53`，即把偏离打对折。样本越多收缩越轻，`p → ∞` 时还原为纯比率法。

**近 6 场状态修正**：权重 0.15，且要求双方近 6 场样本 ≥4 场，否则不启用。修正只作用于 λ，不改变 w。

```js
lamH *= 1 + 0.15 * (ratioH - 1)
```

`ratioH` = 近 6 场「进球 0.6 + 失球 0.4」的综合速率 ÷ 赛季同口径速率。权重故意压得很低——状态是最容易被过度解读的变量。

### 2.3 融合

```
λ = (1 − k) · λ_市场 + k · λ_独立,   k = 0.35
w = (1 − 0.5k) · w_市场 + 0.5k · w_独立
```

**k 为什么偏小（0.35）：** 市场 λ 里含首发票、伤停、动机等模型看不到的信息，独断地相信独立模型会丢掉这些。但 k 必须显著大于 0，否则模型回到 v1 的复述状态。0.35 是让独立模型能在 λ 上造成 ±0.3 球量级偏离的最小权重，这个幅度刚好能让概率层面出现 3–8pp 的差异，足以被判定规则捕捉，又不至于压过市场。

**w 为什么给独立模型一半权重：** w 刻画强弱分配，市场对此更准（它见过双方完整阵容），所以独立模型的 w 只影响 0.5k = 0.175 的份额。

### 2.4 从 λ 到全部市场

`grid(λ, w, ρ = −0.10)` 产出 12×12 比分矩阵，然后一次性导出：

| 市场 | 计算方式 |
|---|---|
| 胜平负 | 对角线上/下求和 |
| 让球胜平负 | `net = 主进球 − 客进球 + hc` 三分 |
| 总进球桶 | `min(主+客, 7)` 归并成 8 档 |
| 总进球区间 | 0-1 / 2-3 / 4-6 / 7+ |
| 大小球 2.5 | `主+客 > 2.5` 求和 |
| 双方进球 | `主>0 且 客>0` |
| 正确比分 | 单元格按概率排序取 top-N |
| 半全场 | 上下半场各分 λ/2，枚举 4×4 上半场 × 4×4 下半场按 9 项归并 |

ρ = −0.10 用于压低 0-0、1-0、0-1、1-1 四个低比分格。它修正的是「低比分被独立泊松高估」这一已知事实。

## 三、回测校准（33 场实测）

样本：上一轮 42 场中已完赛的 33 场（8 场凌晨场次日补充确认 + 25 场常规场）。

### 3.1 方向命中率

| 口径 | 命中 | 命中率 |
|---|---|---|
| 去水概率第一方向 | 20 / 32 | **62.5%** |
| 支持率第一方向 | 17 / 32 | **53.1%** |
| 模型第一方向（焦点 7 场） | 5 / 7 | 71.4% |

**结论：跟随市场比跟随人气高 9.4pp。** 人气方向命中率比定价方向低近 10 个百分点，这是本轮最稳的一条。

### 3.2 定价与资金分歧场次

| 编号 | 实际 | 定价倾向 | 资金倾向 |
|---|---|---|---|
| 日018 莱切 vs 热那亚 | 客胜 | 客胜 ✓ | 平局 ✗ |
| 日023 毕尔巴鄂 vs 皇家社会 | 主胜 | 主胜 ✓ | 客胜 ✗ |
| 日024 格雷米奥 vs 米内罗竞技 | 主胜 | 主胜 ✓ | 平局 ✗ |

分歧场次 3 场：**定价方 3/3，资金方 0/3。** 样本极小，但方向与 3.1 一致，因此 v2 把「分歧时采信去水方向」写成硬规则。

### 3.3 冷端 / 热端：v1 的核心逻辑被证伪

v1 报告的核心执行建议是「热端回避 + 冷端价值小注」。用「实际兑现率 vs 盘口隐含概率」检验（这是唯一有统计意义的比较方式）：

| 分层 | 样本 | 实际兑现 | 盘口隐含 | 偏差 |
|---|---|---|---|---|
| 冷端 Δ ≤ −8pp（v1 推荐的价值池） | 30 | 30.0% | 26.3% | **+3.7pp** |
| 中性 −8 < Δ < +10pp | 44 | 22.7% | 30.2% | −7.4pp |
| 热端 Δ ≥ +10pp（v1 建议回避） | 22 | 59.1% | 49.2% | **+9.9pp** |

30 样本的标准误约 8.0pp，22 样本约 10.7pp。**+3.7pp 和 +9.9pp 全部落在噪声内。**

**所以：Δ（支持率 − 去水概率）在本样本中没有可靠的定价含义。** 冷端不构成买入理由，热端也不构成卖出理由。v2 因此取消了「Δ ≤ −8pp 即小注」这条规则。

Δ 唯一保留的用途是**风险提示**：热端 Δ ≥ +15pp 时价格确实不含补偿，标「回避」是价格判断而非胜负判断。

### 3.4 正确比分：单值预测完全失效

焦点 7 场的模型 top-N 覆盖情况：

| 口径 | 命中 |
|---|---|
| top1（唯一比分） | **0 / 7 = 0%** |
| top3 | 3 / 7 = 42.9% |
| top5 | 5 / 7 = 71.4% |

top1 全错。7 场实际比分是 2-2、3-1、2-1、0-1、2-0、2-1、1-2，而模型 top1 有 5 场都是 1-1。

**规则：永不给「最可能比分」单值。** 只给带概率的 top-5 排名分布，并同时给出累计覆盖率。

### 3.5 大小球：唯一表现好的衍生市场

| 口径 | 命中 |
|---|---|
| 大/小 2.5 方向 | 6 / 7 = 85.7% |
| 让球盘（报告给出的那一侧） | 2 / 3 = 66.7% |

33 场实际总进球分布：0 球 1 场、1 球 6、2 球 7、3 球 9、4 球 5、5 球 2、7 球 2、9 球 1。场均 **3.03 球**，大 2.5 占 **57.6%**，双方进球 **57.6%**。

### 3.6 赔率分段（供下一次校准对照）

| 热门赔率 | 实际命中 | 盘口预期 | 偏差 |
|---|---|---|---|
| <1.50 | 8/9 = 88.9% | 66.8% | +22.1pp |
| 1.50–2.00 | 7/12 = 58.3% | 49.8% | +8.5pp |
| 2.00–2.50 | 4/10 = 40.0% | 40.4% | −0.4pp |
| ≥2.50 | 1/1 | 34.9% | — |

超短赔（<1.50）9 场全中 8 场，高出盘口预期 22pp。样本太小不能当结论，但**下一轮要重点复核这一段**：如果连续两轮都大幅高于隐含，说明竞彩在超短赔上有系统性低估。

## 四、待验证清单（下一轮必须做）

1. 超短赔 <1.50 的偏差是否复现（本轮 +22.1pp，n=9）
2. 分歧规则是否复现（本轮 3/3，n=3）
3. 独立模型是否真的比市场准——本轮焦点 7 场模型 5/7，但样本不足；下一轮要看全量
4. 大小球方向命中率（本轮 85.7%，n=7）能否保持
5. k = 0.35 是否最优——需要至少两轮样本才能调
6. Δ 在更大样本下是否真的无效（本轮 n=96 个选项）

**校准纪律：单轮 30 场左右的样本，标准误普遍在 8–10pp。任何小于 15pp 的偏差都不要写进结论，只写进待验证清单。**
