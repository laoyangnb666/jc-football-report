# 报告结构与排版

## 〇、两篇式结构（v3 起，数据分析与预测严格分离）

报告分为两篇：**第一篇只摆事实（数据怎么来的、盘口怎么动的），第二篇只给结论（买什么、买多少、为什么不买）。** 读者应该能只看第二篇做决策，只看第一篇核查依据。

| 篇 | 章节 | 内容 |
|---|---|---|
| 封面 | — | 标题、场次、margin、λ 来源、快照时间、免责 |
| **第一篇 数据分析** | 1 回测校准 | 上一轮逐市场命中率 + 盘口隐含对照 + 待验证清单状态 |
| | 2 定价引擎 | margin、去水、λ 三来源（市场/独立/伤停修正后）、比分矩阵、总进球逐桶 EV |
| | 3 基本面情报 | 官方伤停表、历史交锋、盘路（主客分开）、天气场地 |
| | 4 市场情报 | 初盘→即时（欧赔/亚盘/大小球）、竞彩 vs 国际偏离、人气税热冷两端 |
| | 5 数据卫生 | 八条检查项、源清单（含访问时间）、缺失字段、伤停修正披露 |
| **第二篇 预测与方案** | 6 逐场综合预测卡 | 每场：①胜平负 ②总进球（方向+8桶）③比分 top-5 分布 |
| | 7 逐场购买方案 | 每场：级别（主推/小注/观察/回避）+ 玩法 + 选项 + 赔率 + 仓位 + 理由；焦点场加详 |
| | 8 全量总表 | 每行：赔率/去水/支持率/λ/综合预测/级别/方案 |
| | 9 执行层 | 串关测算（全部标 EV，结论固定单关优先）、资金管理、当日组合建议 |
| | 10 风险披露 | 免责、复核时点（开赛前 60 分钟重跑） |

## 〇.1 购买方案层（v3 核心新增）

每场必须给出**完整购买方案**，不允许只写「关注/观望」就结束。级别定义：

| 级别 | 含义 | 仓位 |
|---|---|---|
| 主推 | 有跨轮回测支撑的结构性信号，模型与市场同向 | 计划资金 1–2% |
| 小注 | 单一市场有正 EV（让球盘 EV>2%、大小球模型与盘路同向） | 0.5–1% |
| 观察 | 无边际或信号冲突；写明「等什么」（首发/临场价格） | 0 |
| 回避 | 人气过热（Δ≥+15pp）且模型不支持 | 0，并注明为什么 |

方案字段：`玩法（胜平负/让球/总进球/比分）+ 选项 + 赔率 + 模型概率 + 隐含概率 + EV + 仓位 + 一句理由`。

**焦点场加详**：人气 Δ≥15pp、伤停修正 ≥0.2、价格移动 ≥0.15 三者居其一即为焦点场，方案必须包含：
1. 主选玩法与备选玩法
2. 比分娱乐仓建议（≤0.5%/注，从比分分布取 top2）
3. 「什么情况下放弃」——临场否决条件（如首发显示关键球员回归）

**超短赔主推规则**（两轮回测 11/12=91.7% 对隐含 67%）：去水第一方向概率 ≥66% 且模型同向且该侧伤停修正 ≥−0.15 且资金方向无分歧 → 主推单关。任何一条不满足即降级为观察，理由写明。

## 〇.2 逐场购买方案的写法

正例：

```
周三004 费内巴切 vs 利物浦｜主推｜焦点
  主选：胜平负（单关）客胜 @1.33｜模型 62.0% / 去水 66.0% / 隐含 75.2%｜仓位 1–2%
  理由：超短赔区跨轮回测 11/12=91.7%；模型同向；费内巴切换帅+5 人伤，修正后 λ 差仍支撑客队
  否决条件：临场首发显示萨拉赫/范戴克全部轮休 → 放弃
  比分娱乐仓：1-2（9.7%）、1-1（9.3%）各 0.5%
```

反例（禁用）：

```
周三004 看好利物浦
周三004 利物浦实力强，推荐客胜（无仓位、无赔率、无否决条件）
周三004 观望（没写等什么）
```

## 一、章节结构（逻辑）

按七层顺序，层数不可省略；页数随场次与数据可得性浮动，不写死页码。

| 顺序 | 章节 | 必含内容 |
|---|---|---|
| 1 | 封面 | 标题、在售场次数、玩法覆盖数、统一 margin、λ 来源（市场/独立/融合 k）、数据源数与快照时间、免责 |
| 2 | 执行摘要 | 五条结论，每条带数字；末尾给七层目录 |
| 3 | **第一层 回测校准** | 上一轮逐市场命中率表、每项配「盘口隐含」对照、分歧场次记录、待验证清单状态 |
| 4 | 第二层 定价引擎 | margin 分布、去水公式、λ 三来源对照表、比分矩阵、总进球逐桶 EV |
| 5 | 第三层 基本面 | 伤停表（含「对盘口的实际影响」列）、动机与赛程、xG 与进球背离、**盘路表（让球胜率/大小球率，主客分开）** |
| 6 | 第四层 市场情报 | 初盘 → 现价（欧赔 + 亚盘 + 大小球三张）、人气税热冷两端、为什么不做反向 |
| 7 | 第五层 细分市场 | 让球盘 EV 表、大小球、比分与半全场原则、混合过关乘方损耗 |
| 8 | **第六层 逐场综合预测** | 每场一张卡片：比分 top-5 分布 → 总进球区间与桶 → 胜平负 → 让球 → 双方进球 → 判定 |
| 9 | 全量总表 | 每行含「综合预测」与「判断」两列，行数 = 在售场次数 |
| 10 | 第七层 数据卫生 | 八条检查项逐条给状态；源清单表；缺失字段；风险披露 |

## 二、逐场综合预测的写法

顺序固定，**由可靠度从高到低**排列：

```
① 胜平负   主胜 66.8%     [主 66.8% / 平 20.4% / 客 12.9%]
② 总进球   2-3 球 44.6%   大 2.5 60.6%   双方进球 是 53.8%
   桶分布  0球5.2% 1球11.9% 2球22.3% 3球22.3% 4球17.5% 5球11.0% 6球5.7% 7+球4.1%
③ 比分5    2-0 10.9% | 2-1 9.8% | 1-1 9.6% | 1-0 8.9% | 3-0 8.1%   （累计 47.3%）
④ 让球盘   主 44.2% / 平 22.5% / 客 33.2%   （让 −1）
⑤ 判定     观望｜模型与去水偏差 1.5pp，定价有效；人气最大偏离 +10pp
```

**硬约束：**

- 比分只给 5 个，且必须带概率与累计覆盖率。**任何位置都不允许出现「预测比分 1-1」这样的单值句式。**
- 总进球必须同时给「区间」和「8 桶分布」。区间是判断用，桶分布是给总进球玩法用。
- λ 必须拆成三个数：市场 λ、独立 λ、融合 λ 与权重 k。只给融合值等于隐藏了模型的信息来源。
- 判定必须与预测自洽：不能写「主胜 66.8%」却给「回避」。

## 三、全量表列定义

`编号 | 联赛 | 对阵 | 开赛 | 让 | 赔率 主/平/客 | 去水概率% | 支持率% | λ(市场/独立) | 综合预测（胜平负｜总进球｜比分top3） | 判断`

- 「判断」= `level + pick`，与 `verdict` 输出逐字一致
- 「综合预测」列压缩为：`主胜 66.8%｜2-3 球｜2-0 10.9%`
- 焦点行加浅绿底
- 未开售胜平负的场次，赔率列标「让」，综合预测基于让球盘与独立模型
- 表格字号 8.2–8.5px，数字等宽 + `tabular-nums`

## 四、逐场判断清单的写法

每行必须同时具备：级别、选项、赔率、理由（至少一个数字）。

正例：

```
周一004 亚特兰大 vs 帕尔马｜观望｜不参与｜模型与去水偏差 1.5pp，定价有效；人气最大偏离 +10pp
周二008 曼联 vs 罗马｜关注｜主胜 2.10｜资金在客胜（Δ+38pp）与定价相反，回测中此类场次定价方 3/3 命中，采信定价
周一008 本菲卡 vs 阿尔维卡｜关注｜让球盘 客胜 3.05｜模型 29.4% vs 隐含 27.2%，EV +7.1%
```

反例（禁用）：

```
周一004 亚特兰大实力强，看主胜
周二008 双方都有机会，谨慎
周一002 预测比分 1-1
```

## 五、排版 token

```
纸面 #F7F4EE   墨 #17202A   次级文字 #6B6355
绿 #14532D / #2FA36B   红 #9F1D1D   琥珀 #92600A
细线 #D9D2C4   封面底 #101820   封面字 #E8E3D8
```

字体族：标题 `serif`、正文 `sans-serif`、数字 `monospace`。不写具体字体名，靠通用族保证跨环境一致。

字号层级：

| 元素 | 字号 |
|---|---|
| 封面主标题 | 42–46px |
| 章节标题 | 20–21px |
| 小节标题 | 12.5–13px |
| 正文 | 10.5px |
| 表格 | 8.2–8.5px |
| 表注 / 脚注 | 8px |

## 六、排版硬约束

- 不用 kicker / eyebrow 小标签；章节直接给标题
- 不做渐变文字；不用零偏移阴影；彩色边线不超过 1px
- 正文对比度 ≥ 4.5:1；表格不用斑马纹，只用细横线
- 章节标题上边 2px 实线，标题与线之间留 7px
- 数据说明放在表格下方，8px，颜色次级
- 页边距：内容页 `14mm 14mm 12mm`；封面高 296mm，避免 297mm 溢出成两页
- 每个 `.sec` 设 `page-break-after: always`，最后一节取消
- 卡片、表格行设 `page-break-inside: avoid`，避免跨页断行
- 总分进球桶用 8 格横向条形；比分分布用「比分 + 概率 + 细横条」三列，不用饼图
