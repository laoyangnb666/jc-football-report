# 分析逻辑总纲

这是分析一场比赛的完整检查表，也是建库/建模板的字段清单。每个条目后面标注三件事：

- `[源]`：去哪个源取（竞=竞彩官网，捷=捷报，吧=直播吧，搜=联网搜索，算=脚本推导）
- `[用]`：取到之后干什么 —— `模型` 表示直接进定价，`报告` 表示写成文字进正文，`背景` 表示只做佐证不改数字

原则：**能被盘口定价的东西进模型，不能定价的东西进文字。** 不要把情报直接手动改成概率，除非写明修正幅度。

## 一、球队实力与状态（基础层）

### 1.1 进攻
| 条目 | 源 | 用 |
|---|---|---|
| 场均进球（赛季 / 近5 / 近10） | 捷·数据、搜 | 模型（拟合 λ） |
| xG 整体、实际进球 − xG 偏差 | 搜（FBref/Understat/Sofascore） | 模型（评级） |
| 场均射门、射正、禁区内外射门比 | 搜 | 模型（辅助） |
| Big Chances 次数与转化率 | 搜 | 报告 |
| 射门位置分布（剔除点球） | 搜 | 背景 |
| 进球时间分布（上半/下半/75 分钟后） | 捷·数据 | 报告（影响总进球与半全场） |
| 先进球 / 先失球后的结果分布 | 捷·数据 | 报告 |
| 进球方式拆解：运动战/定位球/反击/点球 | 搜 | 报告（影响角球与让球判断） |
| 助攻、关键传球、传中成功率 | 搜 | 背景 |
| 进球球员集中度（是否依赖单一射手） | 搜 | 报告（缺阵权重） |

### 1.2 防守
| 条目 | 源 | 用 |
|---|---|---|
| 场均失球、xGA | 捷·数据、搜 | 模型（拟合 λ） |
| 被射门、被射正、允许的 Big Chances | 搜 | 模型（辅助） |
| 零封场次占比 | 捷·数据 | 报告 |
| 失球方式：定位球 / 反击 / 禁区内外 | 搜 | 报告 |

### 1.3 状态趋势
| 条目 | 源 | 用 |
|---|---|---|
| 近 5/10 场战绩，主客分开 | 捷·数据 | 模型 |

## 二、阵容与人员（权重最高）

### 2.1 确定性信息
| 条目 | 源 | 用 |
|---|---|---|
| 官方伤停名单：伤型、预计复出 | 搜（俱乐部官号、跟队记者）、吧 | 模型（修正） |
| 停赛（红牌 / 累计黄牌） | 搜 | 模型（修正） |
| **门将是否首发** | 搜（赛前 1h 首发） | 模型（修正） |
| 国家队征调与归队时间（FIFA 病毒） | 搜 | 报告 |
| 首发 XI 是否公布、与上场差异人数 | 搜（赛前 60–75 分钟） | 模型（≥3 人变动视为轮换） |

### 2.2 阵容质量量化
| 条目 | 源 | 用 |
|---|---|---|
| 缺阵球员重要性评分＝出场时间占比 + xG+xA 贡献 + 不可替代性 | 算 + 搜 | 模型（给出修正百分点） |
| 有/无该球员的历史 xG 差 | 搜 | 报告 |
| 替补深度（替补身价、替补近况） | 搜 | 报告 |
| 预计首发与上场对比 | 搜 | 报告 |

### 2.3 体能
| 条目 | 源 | 用 |
|---|---|---|
| 主力近 14 天出场分钟 | 搜 | 报告 |
| 上场是否踢满 120 分钟 | 捷·赛程 + 搜 | 报告 |
| 年龄结构 | 搜 | 背景 |
| 3–4 天内第二场的历史表现 | 搜 | 报告 |

**修正幅度纪律**：单个关键球员缺阵，对 λ 的影响写成一个明确百分比（经验区间 3%–8%），并在报告里写出「修正前 λ / 修正后 λ」。不允许在没有数字的情况下说「实力受损」。

## 四、比赛情境层（博彩视角的核心）

### 4.1 联赛背景
- 排名、积分、与上下名分差 `[捷/搜][报告]`
- **动机矩阵**：争冠 / 争四 / 保级 / 无欲无求（dead rubber 必须显式标记）`[搜][模型修正]`
- 升班马、黑马的赛季动能 `[搜][报告]`
- 榜首/榜尾球队的盘路（让球覆盖率）`[捷][报告]`

### 4.2 赛程情境
- 上下轮对手强弱（轮换动机）`[搜][报告]`
- 欧战周中作战后的周末联赛表现（历史系统性下滑，经验值：欧战后联赛胜率降 5–8pp）`[搜][模型修正]`
- 杯赛与联赛优先级 `[搜][报告]`
- 国际比赛日前后归队时间 `[搜][报告]`
- 连续客场第几站 `[搜][背景]`

### 4.3 主客场
- 主客战绩严格分开 `[捷][模型]`
- 主场场均进/失球 vs 客场 `[捷][模型]`
- 特定对手的客场魔咒 `[搜][背景，不写成数字]`
- 时差 / 海拔 / 天然草 vs 人工草 `[搜][报告]`

### 4.4 其他
- 天气预报（雨雪 → 小球、传球型球队受限）`[搜][模型修正]`
- 球场容量与氛围（德比、售罄）`[搜][报告]`
- 裁判：场均红黄牌、判点率、执法该队历史 `[搜][报告，罚牌与点球相关]`
- VAR 场次（点球红牌频率）`[搜][背景]`

动机是全表最难量化的一项。**规则**：动机明确（争冠/保级）→ 允许 ±2pp 修正；动机模糊 → 不修正，只在文字里提示。凭空给「无欲无求」扣分是常见的过度拟合来源。

## 六、盘口与市场情报（机构独有）

### 6.1 价格行为
| 条目 | 源 | 用 |
|---|---|---|
| 开盘价 → 当前价，变动轨迹（谁先动、动多少） | 捷（初盘）+ 竞（现价） | 模型（做「价格移动」栏） |
| 亚盘让球与水位变化 | 捷·亚盘 | 报告（与欧赔偏离对照） |
| 大小球盘口从开盘至今的升降 | 捷·大小球 | 报告 |
| 交易所成交量与价格（Betfair / 竞彩成交量） | 搜 | 报告（聪明钱证据） |
| 自家价 vs 市场均价的偏离 | 竞 + 捷 | 报告（谁领先谁跟随） |

### 6.2 资金情报
- 重注出现的时间与方向（sharp money）`[竞·支持率变化][报告]`
- 公众资金 vs 职业资金比例（支持率是公众代理变量，不等于职业资金）`[竞][模型 Δ]`
- 同联赛其他场次的价格联动 `[捷][报告]`

### 6.3 自我风险
- 各结果敞口（本次报告不做真实敞口，只做结构说明）`[算][报告]`
- margin 水平：主流市场 102–108% 正常，冷门/衍生盘更高 `[算][报告]`

**核心纪律**：开盘价是模型观点，现价是全市场加权共识。当两者背离时，默认认为**现价更准**，除非你能写出一个具体的新信息（首发、伤停、天气）来解释这次移动。写不出新信息就不能反向。

## 八、数据卫生（防错层）

逐条给状态（通过 / 已剔除 / 需注意）：

1. **点球剔除后复核 xG** —— 单场点球可抬高 xG 0.75，不剔除会误判进攻力
2. **红牌比赛样本标记** —— 10 人作战场次的 xG 与失球无参考价值，单独标记或剔除
3. **换人与垃圾时间处理** —— 3 球领先后的 xG 稀释，重要场次看前 60 分钟切片
4. **升降级与杯赛轮换场次剔除** —— 动机不同的样本不能混进联赛评级
5. **样本量检查** —— 新升班马、赛季前 5 轮的数据不进入模型权重
6. **数据源一致性** —— 不同供应商的事件定义不同（射门、Big Chances、xA），一个报告内不混用两家的口径
7. **赔率快照时点** —— 同一场的主胜赔率在报告内只能有一个时点，跨时点比较必须标时间
8. **支持率与赔率的同步性** —— 支持率与赔率若不在同一快照，Δ 无意义

任一条未通过，必须在报告对应位置写明「该结论已降级」，不能悄悄带过。
